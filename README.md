# Warehouse Manager

**Warehouse Manager** — универсальная настольная система управления таблицами и складским учётом для Windows с локальной базой данных SQLite, поддержкой ролей пользователей, импорта/экспорта Excel и CSV, конструктором произвольных таблиц и полнофункциональным резервным копированием.

---

## 🚀 Основные возможности

1. **Универсальный конструктор таблиц**:
   - Создание произвольных таблиц без ограничений.
   - 10 типов данных: Текст, Целое число, Дробное число, Дата, Время, Дата и время, Логическое (Да/Нет), Денежное значение, Примечание, Выбор из списка.
   - Готовые шаблоны: *Складской учёт*, *Журнал посещений*, *Учёт товаров*, *Журнал операций*, *Пустая таблица*.
   - Добавление, переименование, удаление и перемещение столбцов на лету.
2. **Специализированный режим складского учёта**:
   - Поля: Фамилия, Имя, Отчество, Тип операции (*Привёз* / *Забрал*), Название товара, Количество, Дата, Время, Комментарий.
   - Автодополнение ФИО и названий товаров на основе ранее сохраненных записей.
   - Автоматическая подстановка текущей даты и времени.
3. **Импорт существующих Excel (XLSX, XLSM) и CSV**:
   - Безопасное чтение файлов без исполнения макросов.
   - Выбор листа, предпросмотр первых строк, автоматическое распознавание типов.
   - Режимы обработки дубликатов: *импортировать все*, *пропускать точные дубликаты*, *предупреждать*.
   - Транзакционный импорт с возможностью отмены.
4. **Экспорт данных**:
   - Форматы: XLSX (с сохранением типов данных, автошириной столбцов и форматированием дат/валют) и CSV.
   - Экспорт таблиц целиком, результатов поиска или выбранных строк.
   - Защита от формульных Excel-инъекций.
5. **Глобальный и расширенный поиск**:
   - Сквозной поиск по всем таблицам системы.
   - Фильтры по столбцам: содержит, равно, начинается с, заканчивается на, диапазоны чисел и дат (*между*).
   - Поддержка кириллицы и регистронезависимый поиск (`wm_lower`).
6. **Высокая производительность**:
   - Проверено на 100 000+ записях: вставка со скоростью > 110 000 строк/сек, выборка страницы за 1.3 мс.
   - Постраничная загрузка (пагинация) в интерфейсе.
7. **Резервное копирование и безопасность**:
   - Горячее создание резервных копий через SQLite Online Backup API без блокировки программы.
   - Автоматическая проверка целостности базы (`PRAGMA integrity_check`).
   - Страховочная копия перед восстановлением данных.
   - Разграничение прав: роли *Администратор*, *Оператор*, *Только просмотр*.
   - Защита паролей алгоритмом PBKDF2-SHA256 (310 000 итераций).
   - Временная блокировка при подборе паролей.
   - 100% локальное хранение данных без скрытых сетевых запросов и телеметрии.

## 📁 Структура проекта

```text
WarehouseManager/
├── main.py                     # Точка входа в программу
├── portable.txt                # Маркер портативного режима
├── build_exe.py                # Скрипт сборки одного исполняемого EXE
├── wm/
│   ├── app_context.py          # Центральный контекст приложения
│   ├── core/                   # Ядро: типы данных, безопасность, пути, ошибки
│   ├── db/                     # Слой базы данных SQLite: модели, репозиторий, движок
│   ├── services/               # Бизнес-логика: таблицы, записи, поиск, импорт, экспорт, бэкапы, пользователи, настройки
│   └── ui/                     # Графический интерфейс на PySide6 (Qt)
│       ├── common.py           # Общие виджеты, диалоги подтверждения
│       ├── styles.py           # Светлая и тёмная темы оформления
│       ├── dialogs/            # Вход, конструктор таблиц, редактирование записи, пользователи
│       ├── models/             # Виртуальная табличная модель с пагинацией
│       ├── views/              # 8 основных разделов интерфейса
│       └── main_window.py      # Главное окно с боковым меню и вкладками
├── docs/                       # Документация и инструкции
└── tests/                      # Автоматические тесты функционала и производительности
```

## 🔑 Вход по умолчанию

При первом запуске автоматически создаётся учётная запись администратора:
- **Логин**: `admin`
- **Пароль**: `admin123`

Пароль и пользователей можно изменить в разделе **Настройки** -> **Управление пользователями**.
