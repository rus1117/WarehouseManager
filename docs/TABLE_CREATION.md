# Инструкция по созданию и настройке таблиц

## 1. Быстрое создание складской таблицы
1. В боковом меню нажмите **Главная** или **Создать таблицу**.
2. Выберите шаблон **«Складской учёт»** (или нажмите кнопку «📦 Создать складскую таблицу» на главной странице).
3. Программа автоматически сформирует оптимальную структуру полей:
   - **Фамилия** (Текст, обязательное, автодополнение)
   - **Имя** (Текст, автодополнение)
   - **Отчество** (Текст, автодополнение)
   - **Тип операции** (Выбор из списка: *Привёз*, *Забрал*, обязательное)
   - **Название товара** (Текст, обязательное, автодополнение)
   - **Количество** (Дробное число, обязательное)
   - **Дата** (Дата, по умолчанию текущая `{today}`)
   - **Время** (Время, по умолчанию текущее `{time}`)
   - **Комментарий** (Примечание)
4. Введите название таблицы (например, *«Складской учёт — Ноябрь 2026»*) и при желании категорию.
5. Нажмите **«Создать таблицу»**. Таблица сразу откроется во вкладке для ввода записей.

---

## 2. Создание произвольной таблицы через конструктор
1. В боковом меню нажмите **«Создать таблицу»**.
2. В поле **«Шаблон»** можно выбрать один из готовых шаблонов:
   - *Складской учёт*
   - *Журнал посещений*
   - *Учёт товаров*
   - *Журнал операций*
   - *Пустая таблица*
3. Используйте кнопки управления столбцами:
   - **+ Добавить столбец**: добавляет новое поле.
   - **Удалить столбец**: удаляет выбранное поле.
   - **▲ Вверх / ▼ Вниз**: изменяет визуальный порядок столбцов.
4. Доступные типы данных для каждого столбца:
   - **Текст**: обычные строковые значения (артикулы, наименования, адреса).
   - **Целое число**: штуки, упаковки, счетчики.
   - **Дробное число**: килограммы, литры, метры.
   - **Дата**: календарная дата (`ДД.ММ.ГГГГ`).
   - **Время**: время в формате `ЧЧ:ММ:СС`.
   - **Дата и время**: точные отметки времени событий.
   - **Логическое (Да/Нет)**: переключатель (флажок).
   - **Денежное значение**: денежные суммы с копейками/тиынами без погрешности округления.
   - **Примечание**: многострочный длинный текст.
   - **Список значений**: выбор из фиксированного списка.
5. Флажок **Индекс (быстрый поиск)**: создаёт индекс в базе данных для мгновенного поиска даже по миллионам записей.
6. Нажмите **«Создать таблицу»**.

---

## 3. Редактирование структуры уже существующей таблицы
- В режиме просмотра таблицы нажмите кнопку **«Структура таблицы»**.
- Вы можете переименовать таблицу, добавить новые столбцы, переименовать старые или сменить их типы (система автоматически сконвертирует существующие данные в новый тип с контролем ошибок).
