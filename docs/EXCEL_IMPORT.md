# Инструкция по импорту старых файлов Excel и CSV

Система поддерживает импорт старых наработок из файлов Microsoft Excel (**XLSX**, **XLSM**) и текстовых файлов с разделителями (**CSV**, **TXT**).

---

## Пошаговый процесс импорта:

### Шаг 1. Выбор файла
1. В боковом меню перейдите в раздел **«Импорт данных»**.
2. Нажмите кнопку **«Обзор...»** и выберите файл на компьютере.
3. Программа мгновенно проанализирует файл. Если выбран файл Excel с несколькими листами, в выпадающем списке **«Лист»** выберите нужный лист для импорта.

### Шаг 2. Назначение импорта
Выберите один из двух вариантов:
- **Создать новую таблицу в приложении**: программа автоматически создаст новую таблицу и наполнит её строками из файла.
- **Добавить в существующую таблицу**: выберите уже созданную таблицу в системе для дозагрузки данных.

### Шаг 3. Сопоставление столбцов
- В таблице предпросмотра отображаются:
  - Исходные заголовки из вашего Excel-файла.
  - Примеры реальных данных из первых строк.
  - Название столбца и автоматически определенный тип данных (Текст, Число, Дата и т.д.).
- При импорте в существующую таблицу укажите, в какую колонку приложения должны попадать данные каждого столбца файла (или выберите «— Пропустить —»).

### Шаг 4. Обработка дубликатов
Выберите желаемый режим:
- **Импортировать все строки**: загружаются все записи без фильтрации.
- **Пропускать точные дубликаты**: строки, полностью идентичные уже имеющимся, пропускаются.
- **Предупреждать о дубликатах**: строки загружаются, а в итоговом окне отображаются номера повторяющихся строк.

### Шаг 5. Выполнение импорта
1. Нажмите кнопку **«Начать импорт»**.
2. Появится окно с индикатором выполнения.
3. При необходимости процесс можно прервать кнопкой **«Отмена»** — благодаря транзакционности базы данных частичные или поврежденные данные не останутся в системе.
4. По завершении программа покажет отчет об успешно импортированных строках и сразу откроет готовую таблицу.
