# Инструкция по резервному копированию и восстановлению данных

## 1. Автоматическое резервное копирование
- По умолчанию система автоматически выполняет ротацию старых копий согласно настроенной политике хранения (раздел «Настройки» -> «Хранить последних копий»).
- Все копии защищены от сбоев питания благодаря режиму транзакций SQLite WAL и полному выравниванию `PRAGMA synchronous = FULL`.

---

## 2. Ручное создание резервной копии
1. В боковом меню перейдите в раздел **«Резервные копии»**.
2. В поле «Примечание» можно указать причину создания копии (например: *«Перед инвентаризацией 15.11»*).
3. Нажмите кнопку **«💾 Создать резервную копию»**.
4. Процесс выполняется в горячем режиме через штатный SQLite Online Backup API без блокировки работы пользователей.
5. Созданная копия отобразится в списке с датой, размером и путем к файлу.

---

## 3. Проверка целостности базы данных
- В разделе **«Резервные копии»** нажмите кнопку **«🔍 Проверить целостность базы»**.
- Программа выполнит аппаратную и логическую диагностику страниц базы данных (`PRAGMA integrity_check`) и проверку всех внешних ключей (`PRAGMA foreign_key_check`).

---

## 4. Восстановление данных из резервной копии
1. Выберите нужную точку восстановления из списка и нажмите **«🔄 Восстановить из выбранной копии»** (или нажмите «Восстановить из внешнего файла...», если файл находится на другом носителе).
2. Подтвердите операцию.
3. **Безопасность**: перед заменой файлов система автоматически создаёт страховочную копию текущего состояния базы (`safety_before_restore_*.db`), исключая риск случайной потери данных.
4. После восстановления база автоматически перезагружается с восстановленными данными.
